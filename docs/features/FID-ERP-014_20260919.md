## 4. CONTRACT

### 4a. `NavBar` — Server Component, đọc cookie qua `next/headers`
```
Đọc session (giống logic `getStationFromRequest` ở lib/auth.ts, viết lại
bản dùng `cookies()` của `next/headers` thay vì `Headers` request) ->
station: "OFFICE" | "FACTORY" | "ADMIN" | null.

Danh sách link ỨNG VIÊN, NHÓM theo mô hình Odoo Operations/Reporting
(xem Mục 2b, Mục 0 #6):

  Nhóm "Nhập liệu":
    { path: "/capture", label: "Quét/Nhập PO+Kho" }
    { path: "/factory/select", label: "Trạm Xưởng" }
    { path: "/wrapping/check", label: "Wrapping" }
    { path: "/lot/update", label: "Cập nhật Lot" }
    { path: "/packing/new", label: "Packing Slip" }
  Nhóm "Báo cáo":
    { path: "/reports/po-progress", label: "Báo cáo PO" }
    { path: "/reports/production", label: "Báo cáo sản xuất" }

Lọc: chỉ giữ link mà `isStationAllowed(station, path) === true`. Nhóm
KHÔNG có link nào sau khi lọc (vd Xưởng lọc "Báo cáo" còn 0 link) -> ẨN
LUÔN cả nhóm, không hiện tiêu đề nhóm rỗng.
station === null (chưa đăng nhập, đang ở /login) -> KHÔNG hiện NavBar.

Góc phải NavBar (đúng quy ước Odoo/Zoho, Mục 0 #4): tên trạm đang đăng
nhập (OFFICE/FACTORY/ADMIN) + nút "Đăng xuất" (gọi POST /api/auth/logout
rồi điều hướng về /login).
```
